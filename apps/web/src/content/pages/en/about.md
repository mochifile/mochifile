## Simple file tools for everyone

Mochifile exists for people who just want the job done: a photo small enough for a form, an iPhone picture that opens on a laptop, a PDF light enough to email. Friendly pages, no jargon, fast on any phone.

## Private by design

Your files are personal: ID photos, documents, voice notes. So Mochifile’s tools run in your browser whenever possible. Your device does the work, and the file never leaves it. When a tool truly needs a server, the page says so before you start, the file travels over an encrypted connection, is processed in memory and is deleted when the job ends.

That is a claim worth checking rather than taking on trust, so we publish the details on the [architecture and data handling](/architecture/) page.

## Open source

The website and the browser tools are public on [GitHub](https://github.com/mochifile/mochifile) under the AGPL-3.0 licence. Anyone can read how a tool works, report a problem or suggest an improvement. Accounts, payments and server-side features live in a separate private repository.
