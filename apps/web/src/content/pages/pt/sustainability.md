A Mochifile existe para deixar os arquivos menores. Para nós, eficiência não é um enfeite de marketing: é o produto. Este é um relato honesto do que isso significa para a nossa pegada, e do que não significa.

## Arquivos menores, menos para transportar

Cada foto que você diminui gasta menos energia para ser enviada pela rede e menos para carregar no celular de alguém. Uma página mais leve move menos bytes a cada visita, durante todo o tempo em que ficar no ar. O byte mais sustentável é aquele que ninguém precisa enviar.

## Seu aparelho faz o trabalho

As ferramentas do navegador rodam no celular ou no computador que você já está usando. Não há envio, nenhum servidor esperando seu arquivo e nenhuma cópia guardada em lugar algum, então um trabalho comum adiciona só um breve esforço no seu próprio aparelho. O código mais pesado é baixado uma vez e depois fica em cache.

## Páginas leves, sem servidores para manter ligados

O site é um conjunto de páginas estáticas servidas pela rede da Cloudflare, sem JavaScript nas páginas que não precisam dele.

## O que não afirmamos

> “A Mochifile não é carbono neutro, e não compramos compensações para a nossa própria pegada. O que podemos garantir é simples: um produto que reduz a transferência de dados, ferramentas que rodam em equipamentos que você já tem e um site que desperdiça muito pouco. Se um dia medirmos ou compensarmos nossas emissões, diremos aqui, com evidências.”
