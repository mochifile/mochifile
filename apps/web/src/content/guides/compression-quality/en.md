Usually, yes, a little. How much you notice depends on how much smaller you make the file and what the photo shows.

## Two kinds of compression

- **Lossless** compression makes a file smaller and gives back exactly the same pixels. PNG works this way, but the savings are limited.
- **Lossy** compression throws away detail the eye barely notices. JPG and WebP photos use it, and the file can get far smaller.

## What Mochifile does

To reach the size you choose, Mochifile lowers the quality of a photo only as far as needed. If even that is not enough, it also makes the photo smaller in pixels, never larger, and shows you the new size. If a photo cannot reach the limit, you see the smallest size it reached instead of a file.

## How to check the result

1. Open the original and the result side by side.
2. Zoom in on faces, text and edges, where problems show first.
3. If it looks right at the size the website will show it, it is fine.

## Tips to keep quality

- Start from the original photo, not from a copy that was already compressed: each lossy save loses a little more.
- Ask for the largest limit the website allows, not the smallest.
- For screenshots and logos, PNG keeps text sharp.
