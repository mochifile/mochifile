You choose the photo, press upload, and the portal answers with a vague error. Most of the time one of four checks failed, and each one has a quick fix.

## 1. The file is too big

Portals often cap the file size, commonly somewhere between 20 KB and a few hundred KB. A phone photo is far larger. Make it smaller with [Compress image](/compress-image/) and pick the limit the portal states.

## 2. The pixels do not match

Some portals want an exact width and height, or a minimum. File size and pixel size are different things: a photo can be small in KB and still too small in pixels. Read the portal's instructions for the exact numbers.

## 3. The format is not accepted

Many portals accept only JPG. A photo saved as PNG, WebP or HEIC can be refused even when it looks fine. In Compress image you can choose to save the result as a JPG.

## 4. The background or framing is wrong

Official photos usually need a plain background, a centred face and no shadows. No file tool can fix a photo that was taken wrongly, so retake it if the portal says so. Mochifile does not crop photos or change backgrounds.

> Rules differ between countries and offices. Always follow the official photo requirements of the service you are applying to.

## Before you try again

- Re-read the size, pixel and format limits.
- Check the file name: some portals reject spaces or accents.
- Try another browser if the upload fails without a message.
