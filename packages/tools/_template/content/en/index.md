## About this page

This is the template tool. Contributors copy it to start a new tool, so this page shows where
each tool's long-form copy goes: an introduction and tips in the Markdown body, and the steps
and a short FAQ in its frontmatter. Each page of a tool, in each language, has its own
Markdown file in `content/<locale>/<key>.md`.
