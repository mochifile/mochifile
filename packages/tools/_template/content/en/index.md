## How it works

1. Choose a plain-text file (`.txt`).
2. Pick UPPER CASE or lower case.
3. Download the converted file.

## About this page

This is the template tool. Contributors copy it to start a new tool, so this page shows where
each tool's long-form copy goes: an introduction, how it works, tips and a short FAQ. Each
page of a tool, in each language, has its own Markdown file in `content/<locale>/<key>.md`.

## FAQ

### Does my file leave my device?

No. The conversion runs in your browser.
