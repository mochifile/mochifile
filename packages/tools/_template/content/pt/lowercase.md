## Como funciona

Esta página já começa no modo **minúsculas**. É para isso que serve uma página de variante: a
mesma ferramenta, com as opções já ajustadas para uma necessidade comum.

1. Escolha um arquivo de texto simples (`.txt`).
2. Baixe o arquivo em minúsculas.

## Perguntas frequentes

### Posso voltar para maiúsculas?

Sim. Mude a opção acima do seletor de arquivo quando quiser.
