## Como funciona

1. Escolha um arquivo de texto simples (`.txt`).
2. Escolha MAIÚSCULAS ou minúsculas.
3. Baixe o arquivo convertido.

## Sobre esta página

Esta é a ferramenta modelo. Quem contribui copia esta ferramenta para começar uma nova, por
isso esta página mostra onde fica o texto longo de cada ferramenta: introdução, como funciona,
dicas e perguntas frequentes. Cada página de uma ferramenta, em cada idioma, tem seu próprio
arquivo Markdown em `content/<idioma>/<chave>.md`.

## Perguntas frequentes

### Meu arquivo sai do meu dispositivo?

Não. A conversão acontece no seu navegador.
