## Sobre esta página

Esta é a ferramenta modelo. Quem contribui copia esta ferramenta para começar uma nova, por
isso esta página mostra onde fica o texto longo de cada ferramenta: introdução e dicas no
corpo do Markdown, e os passos e perguntas frequentes no cabeçalho (frontmatter). Cada página
de uma ferramenta, em cada idioma, tem seu próprio arquivo Markdown em
`content/<idioma>/<chave>.md`.
