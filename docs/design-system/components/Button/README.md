Pill buttons: one primary action per step, in the action colour, never a brand colour.

- **Primary:** `action` fill, `action-ink` label, `label-lg` in the display face, height `target-primary` (56px), `radius-pill`. One per step ("Choose photos", "Download").
- **Secondary:** transparent fill, 2.5px `ink` outline, `ink` label, same height and shape as the primary.
- **On a brand block** (e.g. Premium): primary stays `action`.
- Icons (download arrow) sit left of the label, 20–22px, same colour as the label.
- Press: scale 0.97 for 120ms. Focus: `focus-ring` 3px, offset 2px.
- Never full-width on desktop except inside a narrow card; full-width on phones inside the tool panel.
