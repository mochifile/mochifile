# Mascot
Provisional working vectors of the mascot's four states: `mascot-idle` (waiting), `mascot-squish` (processing), `mascot-happy` (ready), `mascot-error` (error, 404). Colours are fixed (body #FFF4E0, outline #1E1B2E, cheeks #FF8FA3, corner #9B7BEA). Always on a brand block or light ground. A final model sheet and the mascot's name are pending.
